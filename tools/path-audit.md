# Noodle path audit

Generated by `node tools/tests/audit.js`. Demands: where (floor or up), kind (reps, hold, rounds), one side at a time, balance, weight on hands. A pair is flagged when two or more demands change between neighbouring stones. These are read from the move data, so they are a list to look at, not a verdict.
